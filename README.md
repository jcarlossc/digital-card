## 📌 Sobre o projeto

O **DataQuantum Digital Card** é uma página web responsiva criada para funcionar como um cartão de visitas digital.

O projeto reúne, em uma única página, informações profissionais, especialidades, formas de contato e links para portfólio e redes profissionais.

A proposta é oferecer uma apresentação **simples, profissional, responsiva e acessível**, podendo ser compartilhada por meio de um único endereço.

## 🚀 Executando localmente

Clone o repositório:

```bash
git clone https://github.com/jcarlossc/digital-card.git
```

Entre no diretório:

```bash
cd digital-card
```

Como o projeto é uma aplicação web estática, pode ser aberto diretamente no navegador:

```text
index.html
```

Também pode ser executado utilizando um servidor local.

Por exemplo, com Python:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
